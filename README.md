# Durak Online

Browserbasiertes Multiplayer-Kartenspiel (Durak) fuer Freunde – vollstaendig im Browser, ohne Installation.

## Tech Stack
- JavaScript
- - Echtzeit-Spiellogik im Browser
  - - Mehrspieler-faehig via lokales Netzwerk / geteiltem Link
   
    - ## Features
    - - Klassische Durak-Spielregeln vollstaendig implementiert
      - - Kein Account, kein Download noetig
        - - Entwickelt als Freizeitprojekt zur Vertiefung von JavaScript und Web-APIs
